# Addis Ababa Business Profile Card

A one-page styled profile card for a fictional Addis Ababa business. This project focuses on using CSS variables, the box model, typography, hover states, and pseudo-elements.

## Business

**Bole Brew Cafe**

A fictional cafe located in Bole, Addis Ababa, offering coffee, breakfast, and light meals. Customers can also pay using TeleBirr.

## Features

- CSS custom properties defined in `:root`
- Reusable color palette and spacing variables
- Global `box-sizing: border-box`
- Google Font for readable typography
- Centered business profile card
- Padding, border, border-radius, and margin
- Clear heading, tagline, and body text hierarchy
- Contact button with a hover effect
- HSL used for the button hover color
- Decorative pseudo-element using `::before`
- Responsive layout for smaller screens

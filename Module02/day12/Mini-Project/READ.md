# Habesha Eatery

A simple multi-page HTML website for a fictional Ethiopian restaurant located in Bole, Addis Ababa.

The project focuses on semantic HTML, forms, navigation, tables, images, and basic HTML validation.

## Pages

### Reservations

The reservation page allows customers to provide:

- Full name
- Email address
- Phone number
- Number of guests
- Reservation date
- Reservation time

It also includes a menu table showing dishes, descriptions, and prices in ETB.

### Contact

The contact page allows customers to provide:

- Name
- Email address
- Message

It also includes the restaurant's location in the footer.

## Features

- Semantic HTML structure
- Navigation between pages
- Reservation form
- Contact form
- Required form fields
- Email input validation
- Phone number input
- Number input with minimum and maximum values
- Date and time inputs
- Menu table with table headers
- Accessible table structure using `scope`
- Image with descriptive `alt` text
- Page titles and meta descriptions

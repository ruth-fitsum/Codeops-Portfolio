
# Addis Eats

A static React menu application built with Vite for IBT College Canada CodeOps, Module 3, Day 27.

## Features

- Reusable Dish component with PropTypes and default props.
- Conditional Spicy badge.
- Reusable Card component using children.
- Menu filtering by category.
- Empty state when no dishes match.
- Stable dish IDs used as React keys.

## Technologies

- React
- Vite
- JavaScript
- PropTypes
- CSS

## How to Run

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Install dependencies:

   npm install

5. Start the development server:

   npm run dev

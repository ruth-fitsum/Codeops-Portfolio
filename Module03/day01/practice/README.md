
A static food menu built with React and Vite.

## Features
- Reusable Header and Dish components
- Props for dish names and prices
- Menu rendered from an array using map()
- Unique keys for each dish

## How to run
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Technologies
- React
- JavaScript
- Vite
- CSS

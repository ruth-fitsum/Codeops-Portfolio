# Addis Eats

A React food-ordering frontend built as part of CodeOps Module 3, Day 35.

## Features

- React Router routes for Home, Menu, Dish Detail, Cart, and Checkout
- API fetching with loading, error, and empty states
- Category filtering stored in the URL query string
- Dynamic dish details
- Shared cart state using Zustand
- Checkout validation and touched-field tracking
- Simulated sign-in and guarded checkout
- Error boundary and lazy-loaded checkout route
- Responsive layout and keyboard focus styles

## Technologies

- React
- Vite
- React Router
- Zustand
- DummyJSON Recipes API
- CSS
